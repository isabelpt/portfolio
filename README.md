# Personal Portfolio

My portfolio site: a single-page React site showcasing projects, experience, and more.

## Structure

- `src/App.tsx` — assembles the page sections
- `src/components/` — page sections (Nav, Hero, About, Projects, Experience, Writing, Contact)
- `src/content/` — editable content (profile info, projects, experience, skills)
- `api/substack.ts` — Vercel serverless function that fetches the Substack RSS feed
- `public/` — static assets, including the downloadable résumé

## Deployment

Deployed on Vercel, connected to this GitHub repo.
